# 万象「字母 + /」符号快打 · 速查与记忆卡

触发条件：输入码恰好是「一个字母 + `/`」，例如 `d/` → 、
自定义：`wanxiang.custom.yaml` 里 `quick_symbol_text/symkey/<字母>`
换触发符：`quick_symbol_text/trigger`

## 二、三条规律（记规律，不记 26 项）

### 规律 1：成对符号 = 相邻两键，左符号在左键

| 对 | 左键 | 右键 |
|---|---|---|
| 圆括号 | `e/` （ | `r/` ） |
| 圆点 | `f/` • | `g/` ‧ |
| 单引号 | `h/` ‘ | `j/` ’ |
| 方头括号 | `k/` 【 | `l/` 】 |
| 直角引号 | `u/` 『 | `i/` 』 |
| 六角括号 | `o/` 〖 | `p/` 〗 |
| 书名号 | `n/` 《 | `m/` 》 |

7 对 = 14 个键，只要记住"左边那个"，右边就是它的邻居。
（唯一例外：h 和 j 中间隔了一个键，但仍是"左 h 右 j"）

### 规律 2：z / x / c = 语气三连（标点 + 收引号）

从左到右 = 陈述 → 疑问 → 感叹：

- `z/` 。” 句号
- `x/` ？” 问号
- `c/` ！” 叹号

这三个专门用来**闭合引号里的句子**：打完 `“他说` 用 `z/` 补 。”。

### 规律 3：散键靠联想

| 键 | 输出 | 联想 |
|---|---|---|
| `q/` | 重复上次上屏 | Q = 再来一次（Repeat） |
| `w/` | ？ | W = Why，问 |
| `s/` | …… | S = 省略（Sheng lüe） |
| `d/` | 、 | D = 点（Dian） |
| `y/` | · | Y 在键盘正中，中点 |
| `t/` | Tab | T = Tab |
| `v/` | —— | V 形如一道长横 |
| `b/` | % | B 在数字 5 正下方，% 就是 Shift+5 |

## 四、易错提醒

- 中文状态打 `"` 键会自动配对成 “ ”，**不需要** `f/` `g/`（现已改成圆点）。
- 没有 `「」`，只有 `『』`；要港台引号在 custom 里自己加：
  ```yaml
  quick_symbol_text/symkey/u: "「"
  quick_symbol_text/symkey/i: "」"
  ```
- `n/`（嗯）、`m/`（呣）这类单字母音节后接斜杠会被吞成《》，要打"嗯/"就得分词或改用其他写法。
- `/rq` `/sj` `/sym` 等命令是两个字符起头，不受影响。

## 五、练习

```bash
python3 ~/.local/share/fcitx5/rime/练符号快打.py
```

- 显示符号 → 你敲对应字母 → 回车
- 20 题一轮，错题会在本轮重复出现
- 结束给出正确率和最慢/最常错的键
